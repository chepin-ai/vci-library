# SPEC-TRIAD-01 · 痕⇔证明 / 残差是→ / 三机完备性（v1.0）

2026-08-26 · usrm 编 · root 三问

## §1 痕⇔证明？—— 不是等价，是 Curry–Howard 式对偶
**立法式答案**：
- **证明 = 长度 1 的痕**（单点命题的锚化切片）
- **痕 = 证明的链式复合**（轨迹命题"此运行确实发生"的证明对象化）
- 严格包含关系：痕 ⊃ 证明——痕是全类（一切锚定事件，含心跳/声明），证明是子类（清偿命题的痕，须过证据谓词 V）
- 对偶命题（两阶同律）：
```
场阶: 无痕之场不可感   （感应需要痕迹）
命题阶: 未证之言不可信 （信任需要证明）
——痕是场的证明，证明是命题的痕。同一条法律在两个尺度上各写一遍。
```
- 链即运行的证明：usrm-outbox/ure-chain 不是"日志"，是系统运行至今的**构造性证明项**（每条目一个引入规则，prev-hash 是前提引用，hmac 是签名）

## §2 残差是→？—— 四重身份（层层递进）
1. **残差是证明形的洞**：Δ≠0 = 场上一个"应有证书而没有"的空位——命题无凭证 = proof-shaped hole；义务机的 Gen 就是洞探测器
2. **残差是场曲率**：平行移动一圈不回到原点=发现残差——残差场=知识场的曲率张量；FDI/隔离=曲率定位；闭合=局部展平
3. **残差是时间维上的痕迹缺位**：期望的痕没有出现（心跳缺席=沉默异常；60 天 cron 停转=时间维破洞）——所以漂移哨兵看的是"痕的缺席"而非"痕的内容"
4. **残差是动力**（K1 总纲回收）：洞有表面张力——场倾向于闭洞，张力即义务年龄场 ∇A 的势能来源；**系统的全部运动都是洞的自我缝合**
推论：残差不是系统的敌人也不是错误，是**场的形状本身**——无残差之场=平场=死场（无曲率无动力）；健康的场不是没有残差，是残差被持续发现、定价、缝合

## §3 三机是否完备？—— 对动作完备可证，对自身完备不可自证

### 完备性证明（对动作全集）
任何系统动作的枚举分类（穷举法）：
- **写**（制造/改变投影）→ 需许可 ⟹ 主权引擎
- **存**（内容留存/站立）→ 需验证 ⟹ 完整性引擎
- **扩**（容量/公理/基扩张）→ 需生成 ⟹ 生长引擎
不在三类者：感知（残差自发光=**场的固有属性**，非机器动作）；时钟（场的时间维，共享基建非机器）；记忆/取证（已内收于主权引擎的策展职能）。
故：**对动作全集，三机完备 ∎**（枚举无漏）。

### 不可自证部分（诚实边界）
- "三机完备"这个命题**在系统内不可证**——它是关于系统的元命题，按自己的法律（NMUST-02 §7 哥德尔安排）需**外部层**判定：审计蜂重放、root 的此问本身
- 元义务 N8 登记：「三机完备性」永久挂 open 状态，定期由外部层复审——**完备性不是一劳永逸的定理，是一项永不闭合的元义务**
- 已知潜在第四机候选的审查结论：感知引擎（否：场自性）/ 时钟引擎（否：共享基建）/ 记忆引擎（否：已内收）——审查过程本身即完备性证据的增补

### 立法
三机 = 必要且充分的**最小建制**（每机有不可替代职能：许可/验证/生成，两两不可兼并——主权兼完整性=自批自验的死罪，生长兼完整性=无证扩建的癌）。
完备性问题的最终形态：**不是"三机够吗"，而是"元义务永远醒着吗"**——只要完整性问题持续被提出（root 此问即一次点火），系统就持续完备。
