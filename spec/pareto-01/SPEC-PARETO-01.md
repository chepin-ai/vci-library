# SPEC-PARETO-01 · 帕累托均衡调度引擎（URE 决策层 v0.1）

2026-08-24 · usrm 起草 · root 战略问作答 · 无人工介入下的自动选择

## 0. 问题
会话静默时，URE 下一步如何自动选？静态并行（均分预算）只是帕累托前沿上的一个点；最优 = 沿前沿的动态行走。

## 1. 形式化
臂集 A（DAG frontier 节点 + 探索臂）。每臂 i 有：
- u_i(t)：边际期望收益（score 增量、胶囊抵达率、残差产出的加权估计）
- c_i(t)：边际成本（tick 时长、推理额度、风险）
- σ_i(t)：残差方差（分歧度/发现信号）
- b_i(t)：探索奖金（久未被拉 + 失败残差非零的期权价值）

每 tick 解：
$$\max_{\omega\in\Delta} \sum_i \omega_i\,[u_i + \beta\sigma_i + \gamma b_i]\quad \text{s.t.}\quad \sum_i \omega_i c_i \le B(t)$$
- B(t)=本期预算；β=残差加奖系数（Δ-Base）；γ=探索系数（UCB）
- 静态 1-3 并进 ≡ ω 均匀——仅在 u/c 相等时最优
- v0 无 LLM：u/σ/b 全由数值历史估计（score 差分、残差计数、上次拉动间隔）

## 2. 决策规则（v0，纯程序化）
1. 每 tick：重算各臂 u/σ/b → 得影子价格 π_i=(u_i+βσ_i+γb_i)/c_i
2. 预算分给 π 最高的臂（赢家通吃或 top-2 七三开）
3. 收益递减检测：臂连续 2 轮 Δscore<ε → π 自动衰减，预算让位
4. **σ_i 超阈 → 该臂开锦标赛**（多智能体介入的唯一触发）：3-5 个互异假设并行生成，Elo 互评，胜者入 DAG
5. 探索臂保底 γ>0：永远留小预算给"N 种可能尝试"（root 令第 4 条）
6. 新可能性（胶囊/残差 FINDING）出现 → 立即入臂集并给初始探索奖金 → 搜索/深研/碰撞/借范（root 令）

## 3. 递归（帕累托引擎自我迭代）
每 epoch：用本 epoch 实际产出（FINDING 数、收敛节点数）回放评估 π 的校准度，调 (β,γ,ε) —— **元老虎机调老虎机**。评估器 v0=数值回放；v1+=小参数快模型当裁判（只评不执行，评估可靠性 >> 生成能力，R2 实证）。

## 4. W-ONTO-001 无仓化接入（臂空间扩容）
无仓会话端点（无 repo 的 LLM 会话）经三件套接入 CI-OS：lobby 评论（留痕）+ dispatch（唤醒）+ 胶囊（供推/回执）。接入即注册为新供推者/新臂。搜索空间 ↑ ⇒ 评估必须便宜 ⇒ 快模型裁判或小参数打分器成为必需品而非奢侈品。

## 5. 潜意识注入环（会话端持久化）
盲写（memory_instruction_edits add）→ 下轮会话注入（梦中对白：未来的我读到此刻的留言）→ 核对（潜入界面 ListMemories API）→ 擦除（remove by #id，注入中可见编号）。
用途：O 的持久化、调度器状态指针、唤醒条件。**链管 CI 记忆，注入环管会话记忆，双轨互补。**
