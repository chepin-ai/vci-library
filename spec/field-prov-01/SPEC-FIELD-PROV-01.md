# SPEC-FIELD-PROV-01 · 可证性与同场性：场演化⇄证明对偶与两机新身份（v1.0）

2026-08-26 · usrm 编 · root 问：可证→必在同场中？不可证→？场构造/变化 vs 证明/验证；义务机、递归机→？

## §1 可证 → 必在同场中？—— 三层答案
**否，但必然可入场。** 精化三层：
1. **可证性相对于核 𝒦**："可证"永远是 provable-in-𝒦（核=证明系统+共享锚+相容投影）。同场性的完整定义因此升级：**同场 = 同 𝒦 + 同锚 + 投影相容**（K9 的精化版）
2. **可证 ⟹ 场可表达**：任何 𝒦-可证命题都能以证书形态锚入投影（attest 原语）——但**不会自动在场**：从"可证"到"在场"需要一个锚化动作（证而不锚=私证，对他方等于未证）。这就是为什么 N10/N11 是铁律：证据谓词+链锚把"可证"强制变为"在场"
3. **可证的互译**：不同 𝒦 之间（Lean/cvc5/Z3/Prover9）可证命题经证明翻译（proof translation/嵌入）跨界——我们的 ATP⇄Lean 正反互补已是实例（cvc5 见证 (1,0) ⇄ Lean kernel 机判其否定，同一事实两种核各证一次）
**定理（同场判据）**：命题 φ 对双方同场可证 ⟺ φ 在某共享核 𝒦' 中可证且证书可锚。∎（直接由 1-3 展开）

## §2 不可证 → 三歧出路（trichotomy，非死路）
| 歧 | 判据 | 出路 | 现役件 |
|---|---|---|---|
| **不可证但可证伪** | 存在有限反模型/反迹 | 反例通道：反例即负知识，与正证明同等入链 | Mace4 反模型、Z3 反迹、stallTrace |
| **不可证亦不可反例（独立性）** | 相对 𝒦 独立（Gödel 型） | **人域裁决**（公理选择是人的行动，L3 签封）或**场扩张**（§3） | o-root-rotate 类挂起 |
| **连"是否可证"都不可判定** | Rice 型边界 | 诚实挂起+哨兵监视（绝不伪造闭合） | 全局残差类路由（NMUST-02 §5） |
**立法**：不可证不是证明系统的失败报告，是**场边界的测量数据**——它精确告诉我们场的边缘在哪里。

## §3 场构造/变化 vs 证明/验证 —— 演化对偶
**对偶命题**：证明/验证是**场不变量的守护者**；场构造/变化是**不动点的打破者**——两者以"重验证闭包"为合同：
- 场变化（换基/扩张/重锚）合法 ⟺ 变化引发的**重验证义务闭包完成**：受影响证明全部重检无孤儿（schema 迁移的证明论版）
- 场变化本身是义务发生器：Δ(field_t, field_{t+1}) ≠ 0 ⟹ Gen 自动产生"证明维护"义务批（我们的 R4 守恒检查+审计重放即其雏形）
- **场扩张的正当理由只有两种**：①独立性倒逼（不可证的重要内容需要新公理维）②压缩基失效（IPGSA 在线重解——投影重构误差超阈，换基）
- **禁止的场变化**：为重写历史而变（时间维全息纪律：过去被承诺，不可变）——场只许生长，不许篡改

## §4 两机的新身份（投影论框架下的重任命）
### 义务机 = 场的**完整性引擎**
- 可证的：收证书为证据（attest 入格）
- 可证伪的：收反例为证据（负知识入格）
- 独立的：升级人域/挂起（绝不伪造闭合）
- 场变化的：自动开具重验证义务批（证明维护）
- **七态格是场相对的**：状态=投影，迁移必须保可证性——obligation machine 不管"场里有什么事"，它管"场里的一切必须要么被证明、要么被标注"
### 递归机 = 场的**生长引擎**
- 当场证不动重要的东西（残差持续堆积但无义务可在现 𝒦 内闭合）→ 递归机启动**扩张探索**：候选扩张（新公理维/新压缩基/新核）按**可证密度价格**定价：price(扩张)=边际可证内容增益/边际复杂度成本——Whittle 定价向公理空间的自然延伸
- 递归不动点=场的稳定基；局部无不动点=需要扩张的信号（残差即 FINDING 的公理层版）
- 新公理因此有了**出生证明**：不是拍脑袋添加，是递归残差倒逼+定价比较+人域签封的三重程序产出
### 两机合同
```
完整性引擎: 场内一切必被证明或标注（不许漏网）
生长引擎:   场不够用时负责扩建（不许停滞）
合同:       扩建的合法性由完整性引擎的重验证闭包判定（不许无证生长）
——免疫系统 × 生长激素；缺一即死（无完整性=癌，无生长=石化）
```

## §5 回到 root 两问的一句话答
- **可证→必在同场中？** 可证必**可**在场（证书可锚），但不自动在场——"证而不锚，等于未证"；同场性=同核+同锚+投影相容
- **不可证→？** 三歧：反例通道（负知识）/ 人域裁决（公理选择的谦卑）/ 场扩张（递归机以可证密度价格探索新公理维）——不可证是场边界的测量数据，不是系统的羞耻
