# SPEC-CONV-01 · 残差导向内外开放帕累托贪婪递归的收敛/停机条件（v1.0）

2026-08-24 · usrm 立证 · root 命题 · 承接 STRAT-01/02、PARETO-01、DUAL-01

## 0. 命题的精确化（先拆掉一个伪问题）
全局**永不停机是特性不是缺陷**（研究 OS 常转）。故可证的对象是四个性质：
- **H1 任务停机**：每臂/每分支有限时间内终止（done/retired/pruned）
- **H2 资源有界**：现役集、试用池、每 tick 评估成本均有硬界（空间爆炸被吸收）
- **H3 遗憾次线性**：regret(T)/T → 0（臂流存在下仍成立）
- **H4 参数收敛**：元递归权重 (β,γ,ε,θ) 收敛到不动点（临不动点可观测判据）

对象系统：臂流（到达率 λ）+ 试用池探针（成本 c_p）+ 帕累托门禁 + 现役集（|A|≤K_max）+ Whittle 式贪婪分配 + 残差触发放蜂 + 参数级元递归（折扣 γ<1，步长 η_t）。

---

## 定理 1（H1 分支停机 · Lyapunov 法）
**条件**：(a) 收益有界 score∈[0,1]；(b) 递减收益——相邻增益序列非增（R2 实证支持）；(c) 预算硬顶 B_max；(d) 早停规则：连续 k 轮 Δu<ε ⇒ 退役。
**证明梗概**：取势函数 Φ(branch)=剩余预算 + (1−score)。每轮要么 score 增 ≥ε（Φ 减 ≥ε），要么 Δu<ε 计数 +1（k 次即退役，Φ 归零）。若增益恒 ≥ε 则由 (a) 至多 1/ε 轮后 score→1 封顶退役；若增益跌破 ε 则由 (d) 有限轮退役；无论如何 Φ 在有限步内耗尽。□
**失效反例**：无 (c) 且增益构成调和级数（Σ1/n 发散）→ 永不退役 ⇒ 预算硬顶不可省。

## 定理 2（H2+H3 开放臂流稳定 · 流体/排队判据）
**条件**（交通强度）：ρ = λ·β̄ / B < 1（λ 新臂到达率，β̄ 单臂期望预算，B 每 epoch 服务预算）；门禁把有效到达率压为 λ' 使 λ'β̄/B < 1 恒成立。
**证明梗概**：把试用池+现役集看作服务台系统。ρ<1 时流体模型稳定，池长有界；Berry & Fristedt（无限臂 bandits, 1979-85）：探测成本受控 + 折扣存在 ⇒ 存在遗憾次线性的策略；本引擎的"廉价探针+支配门禁+退役"正是该构造的工程版。ρ≥1 时门禁提高拒绝率 ⇒ λ' 下降 ⇒ 系统回稳（以延长发现时延为代价，不爆炸）。□
**失效反例**：无 K_max 且无门禁 → 每 tick 评估成本 O(|A|) 无界增长 → 违反论题 0（元成本爆炸）→ 系统在能做任何研究之前先被自己的调度压垮。

## 定理 3（贪婪策略质量 · Whittle 指数的渐近最优）
**陈述**：restless bandits 的 Whittle 指数策略在臂数 N→∞ 的流体极限下渐近最优（Whittle 1988；Weber & Weiss 1990 有限时域修正；Verloop 2016 渐近最优性）。
**于本系统**：影子价格 πᵢ 即 Whittle 指数的可计算启发式 ⇒ "帕累托贪婪"不是拍脑袋而是有渐近最优地位的策略族；有限 N 下有已知偏差（Weber-Weiss 修正项）——汇报时遗憾界须含此修正，不得宣称精确最优。□

## 定理 4（H4 元递归收敛 · 随机逼近）
**条件**：η_t 满足 Robbins-Monro（Ση_t=∞, Ση_t²<∞，取 η_t=η₀/t）；更新目标的期望场光滑；折扣 γ<1 保持收缩（STRAT-02 §3）。
**证明梗概**：参数更新视为带噪声的梯度步，Robbins-Monro 1951 ⇒ 几乎必然收敛到均场 ODE 的驻点；收缩性（Banach）⇒ 该驻点是唯一不动点。工程判据（M5/M6）：相邻 epoch 参数变化 <ε_param 且遗憾曲线斜率下降 ⇒ 宣称"临不动点"。□
**失效反例**：恒定大步长 → 参数震荡不收敛；η 衰减过快（Ση_t<∞）→ 卡在非驻点。

## 1. 四条件的合取（收敛/停机宪章）
```
H1∧H2∧H3∧H4 成立 ⟺ (预算硬顶+早停ε) ∧ (门禁使 λ'β̄/B<1) ∧ (K_max 有限) ∧ (η_t∝1/t, γ<1)
```
全部七项均为**参数与结构检查**——可在 CI 机判（ATP-lab Z3 可验证参数约束的有限模型；sweeper 每轮自检违例即报警停轮）。

## 2. 空间爆炸 → 张量网络 & IPGSA 接入（答 root 提醒）

新可能性持续进场 ⇒ 可能性空间组合爆炸 ⇒ 显式枚举不可行。但**爆炸的是维度，不是结构**：

**T-a TN 压缩表示**：若可能性场的"纠缠"是局域/短程的（主题近邻强耦合、远邻弱耦合——知识谱系的现实形态），则它满足**面积律**，MPS/PEPS 以键维 χ 压缩表示，表示误差随 χ 受控（χ 即表示预算，与 K_max 同构：K_max 管臂数、χ 管表示精度）。已具桩：tensor-net-01 楔 + tn-lab S1（quimb MPS 缩并 ✅）。

**T-b 选择问题即 Ising/QUBO**：每 tick 的臂激活决策 = 在冲突目标（frustration!）下的离散优化——天然是自旋玻璃地形。**IPGSA/量子启发退火正是为受挫崎岖地形设计**；tn-lab S2 已实证 neal 退火与穷举一致（E=-2.6 对拍 ✅）⇒ 管线已通。arm 激活向量 x∈{0,1}ᴷ → QUBO → neal/IPGSA 求解 → 与 Whittle 排序**双解对拍**（M6 检验必反复：两边夹）。

**T-c 残差场的张量化**：残差驱动场（DUAL-01 §3）表示为张量场后，相变检测（保真度易感度/纠缠熵扫描，ripser 持续同调）给出"发现相"的预警——残差积累到临界 ⇒ 相变 = 范式级 FINDING。

**T-d 收敛条件的 TN 翻译**：χ 有界 ⇔ 表示不爆炸；退火 schedule 缓慢 ⇔ 全局优化不陷入亚稳（与 η_t 衰减同构——**同一类 Robbins-Monro 条件在三个层级复现**：物理退火、参数递归、探索衰减）。
