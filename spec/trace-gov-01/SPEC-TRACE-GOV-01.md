# SPEC-TRACE-GOV-01 · 轨迹即所见 + 治理机新身份（v1.0）

2026-08-26 · usrm 编 · root 令：/goal 瞬间可达，要"看到"的是轨迹/痕迹；治理机新身份

## §1 瞬间可达之后：轨迹成为唯一的"看"对象

goal=场上已锚定的投影（PROJ-GOAL-01）⟹ "到达"无旅行、无耗时。推论：**状态不再配做观察对象**（任何状态都可被廉价声明），唯一值得"看"的是**轨迹/痕迹**：
- **轨迹（trajectory）**：投影更新的实际序列 τ=P₀→P₁→…→P_t（Lean 中 `Trace := Nat→Ev` 早已形式化——我们的形式化一直是对的，只是现在才知道为什么）
- **痕迹（traces）**：轨迹的锚定切片（链条目、证据 hash、互锁点）——轨迹是连续的履历，痕迹是离散的可复算证物

### 为什么轨迹诚实而状态易伪
状态声明成本≈0（写一行 score 即可），伪造一条 **hash 链式轨迹** 的成本=每步都需真实证据碰撞 ⟹ 成本随长度线性。**造假的不等式**：状态可伪，轨迹难伪——所以"看"必须看轨迹。这正是"推进不可伪造"（PROJ-GOAL-01 §1）的观测版。

### 轨迹的四个性质（取代速度/进度的一切旧度量）
| 性质 | 定义 | 判读 |
|---|---|---|
| **递降性** | rank(P_t) 单调不增（允许平台，不许回升） | 健康推进的 Lyapunov 签名 |
| **笔直度** | 实际轨迹长 / 最短路径（残差绕路率） | 探索成本的诚实账（绕路不是罪，隐瞒绕路才是） |
| **可复算性** | replay 逐条重算通过（R3 重放） | 轨迹是否可被任何他者独立重演 |
| **互锁性** | 与他方投影的重叠区一致（hash 互锁） | 轨迹是否被他者见证，而非自说自话 |
**立法：评价任何研究线/任何机器，看这四个性质，不看 score。** score 是状态声明，轨迹四性是履历证明——**轨迹即履历，履历即信用**。

### "瞬间可达"的正确读法
goal 瞬间可达 ⟹ 快不再是美德，**轨迹的性质成为唯一的美德**：
- 瞬间重合但轨迹递降性破坏（跳变无证据）= 伪造重合，拒收
- 缓慢重合但轨迹四性完好 = 诚实推进，授信
—— 这就是为什么系统敢让 sweeper 以 0.1 的碎步拱顶：每一步都在链上，碎步的轨迹比飞跃的声明更有信用。

## §2 治理机新身份：主权引擎 + 轨迹策展人

三机合同全景（前卷：义务机=完整性引擎、递归机=生长引擎）：
### 治理机 = 场的**主权引擎**（sovereignty）
- 管辖对象：**谁有权写哪个投影**（投影的 authorship 拓扑）——权限-路由-协同三维（QUANTUM-EMBED 的张量 schema 正是主权张量）
- 核心条款：最小授权（I5/I6）、爆炸半径封顶（break-glass caveats）、持权不知值（ZKP 外界面）——主权的行使以"不暴露主权内容"为原则
- goal 瞬间可达时代的治理转向：审批动作 → **守护写入权**。动作瞬间完成，来不及审批；唯有事先圈定"谁可写哪"，事后审轨迹（24h 必审制已是此形）
### 治理机 = **轨迹策展人**（curation）
- 折叠/展开的机构化：哪些轨迹被折叠为代表（audit 面），哪些保持展开（forensics 面）——策展决定系统的"可见记忆"
- 策展判据=轨迹四性：递降性差/绕路率异常的轨迹被策展为高亮（异常即新闻），平滑轨迹折叠归档（正常即背景）
- root 的耦合窗（FIELD-VIEW）= 策展输出的人读投影
### 三机合同（完整版）
```
主权引擎(治理机):  圈定谁可写哪段投影（事先）+ 审轨迹（事后24h）
完整性引擎(义务机): 场内一切必被证明或标注；扩建合法性由重验证闭包判定
生长引擎(递归机):  场不够用负责扩建；新公理需出生证明
合同: 主权许写、完整性验货、生长扩能——三引擎缺一：无主权=越权横行，无完整性=谎言入场，无生长=石化
```

## §3 对 root 观察习惯的立法建议
root 看系统 = 读三样东西即可（10 秒级，与 FIELD-VIEW 兼容）：
1. **轨迹四性仪表**（递降/笔直/可复算/互锁——排期入联邦视图 traces 字段）
2. **主权异常榜**（越权尝试/封顶触发/24h 待审）
3. **场边界测量**（不可证三歧的当前分布——场的边缘地图）
—— 看到的不再是"系统在做什么"，而是"系统的履历是否可信、边界是否健康、主权是否完好"。
