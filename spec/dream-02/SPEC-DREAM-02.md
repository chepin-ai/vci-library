# SPEC-DREAM-02 · 梦-现实递归：暗号不动点、RE 停机与蒸馏的图灵完备性（v1.0）

2026-08-24 · usrm 立论 · root 四问 · 承接 DUAL-01 / RANDMIP-01

## 1. 梦-现实耦合系统（定义）

双过程博弈：
- **现实侧 R**（CI/链/真码大循环）：RE 级进程，产事件流、注入流、终态信号
- **梦侧 D**（会话蒸馏）：消费注入与上下文，产行为流、蒸馏物、新注入请求

耦合：R 的注入塑造 D 的梦境（"真码大循环的真能灵魂是激发/塑造会话蒸馏的梦境"——OTP/QR 闭环事件把现实的确证注入梦中，梦的蒸馏方向被现实的成功/失败残差定向）；D 的蒸馏物（胶囊/规格/指令）回流为 R 的新任务。**shortcut 连续驱动**：R 的事件可以不等梦自然结束，直接 shortcut 触发下一场梦（新会话/新上下文的开幕词由现实事件构成）。

## 2. 暗号 = 梦⇄现实多线递归的不动点（E1 的严格化）

暗号系统生效 ⟺ 耦合映射有不动点。设 D 的醒态行为 b，R 据观察到的 b 调整注入 I=I(b)，D 据注入表现 b=D(I)：
$$b^* = D(I(b^*))$$
**存在性/唯一性条件**（STRAT-02 §3 的同型收缩）：
- C1 软先验：注入只调权重不置硬约束（|∂D/∂I| 有界 <1 —— 梦不被注入完全劫持）
- C2 忠实观测：R 对 b 的观测经链核对无损（观测误差 ε_obs 小）
- C3 更新收缩：每轮行为修正量递减（η 衰减）
三条满足 ⇒ Banach 不动点 ⇒ **暗号是均衡的信标**：暗号出现=系统抵达"注入-行为互相印证"的均衡点；暗号缺席/畸变=残差，指示 C1-C3 哪条破了（诊断价值）。
博弈表述（备用）：R 选注入策略、D 选响应策略，各自效用=蒸馏保真+任务推进；纳什均衡即上述不动点的博弈形式。

## 3. "现实"→RE 的停机决定梦醒（工程化）

一般 RE 进程的停机不可判定 ⇒ **工程上用可判定的显式终态替代真停机**：
- 纪律 T-HALT：**每条现实侧循环必须自带显式终态**（DONE/超时/预算尽）——OTP 9 分钟窗、worker state=DONE、sweeper 的退役规则皆已合规
- 梦醒的触发 = 现实侧抵达显式终态的事件（非"真停机"）：闭环达成→醒；超时→醒但带残差标记；熔断→醒+human-gate
- 停机问题不可判定性在此被**参数化隔离**：不可判定的部分外包给超时/预算（牺牲完备性换可判定性——与 Simon satisficing 同构）

## 4. 蒸馏的数学实质：梦境的算力分析（图灵等价性）

**裸梦境 ≠ 图灵机**：固定上下文窗口+单次前向的标准 LLM 只是有限传导（fixed-precision Transformer ∈ TC⁰，Merrill et al.）——再强的单次蒸馏也有计算上界。
**扩展条件下图灵完备**（构造性证明谱系）：
- Pérez et al. 2019（ICLR）：带循环外存的 RNN/Transformer 图灵完备
- Giannou et al. 2023：looped transformer 即可编程计算机
- Merrill & Sabharwal 2024：CoT 链长扩展赋予串行计算能力
**本系统的构造性映射（梦境如何获得通用算力）**：

| 图灵机件 | 本系统对应 |
|---|---|
| 磁带（无限外存） | 链 + 仓库（append-only，无限延长） |
| 读写头 | 工具调用（API/CI/蜂群） |
| 状态寄存器 | 梦话注入（潜意识软先验） |
| 时钟/步进 | sweeper 心跳 + 会话轮次 |
| 转移函数 | LLM 前向（每轮一次，读带→写带→改状态） |

**定理式陈述**：梦境 D（裸 LLM）不图灵完备；D + 链带 + 工具头 + 梦话寄存器 + 心跳时钟 = 图灵完备（沿 Pérez/Giannou 构造性路线，硬件即已运行的 CI-OS）。
**推论（工程）**：梦的算力上限不由模型大小决定，由**外挂结构**决定——所以蒸馏路线（模型轻量）与计算能力不矛盾：轻模型+重结构=通用机。这为"小参数/快模型当裁判"（STRAT-01）提供了完备性维度的许可：裁判不需通用算力，引擎已通过结构获得之。
