# SPEC-PROJ-GOAL-01 · 共享投影下的推进/证明/前瞻（v1.0）

2026-08-26 · usrm 编 · root 问：/goal 与起点&中间态（目前研究形态）共享投影，所谓推进/证明/前瞻→？

## §0 前提的形式化
场 Φ 上三个投影切面：P₀（起点投影）、P_t（中间态投影=当前研究形态）、P_∞（goal 投影）。
关键：P_∞ 不是"尚未存在的外部未来"——它**已被承诺在场上**（goal 声明即锚：DIRECTIVES 条目/roadmap 节点的 declared 态+hash 锁定）。时间维全息纪律（FIELD-TIME-01）：过去被承诺，**未来也被承诺**——goal 是场上一个已锚定但尚未与 P_t 重合的投影。

## §1 推进 → 不动点算子的实际迭代（不是移动，是重合）

**推进 = P_t 向 P_∞ 的投影重合过程**，算子化：
```
推进算子 𝔸: P_{t+1} = P_t ⊕ discharge(o*)      （清偿一个义务=投影更新一步）
目标达成 ⟺ dist(P_t, P_∞) = 0 ⟺ 残差场在 goal 切面全零
```
- 没有"从这里到那里"的旅行——只有投影间残差 Δ(P_t,P_∞) 的不断清偿；每个义务闭合都是两块投影拼图的咬合
- 速度的正确度量不是"走了多远"，是 **rank(P_t)** 的递降率（见 §3）
- 现役实证：URE 的 tick 序列就是 𝔸 的迭代轨迹；五个 done 节点=五次投影重合事件（score≥0.8 即 dist 低于阈值的工程判据）
- **推进的不可伪造性**：重合必须由证据锚见证（N11），否则只是 P_t 自称重合——声明与重合的区别=有没有 hash 互锁

## §2 证明 → 投影间蕴含的 kernel 证书（不是外部背书，是互锁凭证）

**证明 = P_t ⊢ P_∞ 的可达性证书**，三层形态：
1. **LeadsTo 层**（已 kernel 证）：`fair_leads_to_terminal : Valid τ → Fair τ → ∀t₀, LeadsTo τ Terminal t₀` —— 公平性下当前投影必演化至终态投影；这是"推进必达"的证明版，其构造件 rank 函数正是下节的前瞻信号
2. **互锁层**：证明=两投影在重叠区的一致性凭证（hash 互锁）——证明一个研究结论=给出从 P_t 到 P_∞ 的收缩路径（trans 边序列全过 contract 检查），路径的每个锚都可复算
3. **反例层**：证明的另一半是证伪通道（正反互补纪律）——P_∞ 不可达的反例（Mace4/Z3 反迹）同样是知识；**证明系统的健康=既能发证也能开死亡证明**（stallTrace_not_leadsTo 已 kernel 机判）
- 在此框架下，"证明"不再需要外部权威：kernel（Lean）+求解器（ATP）+锚互锁（链）构成内禀凭证体系；外部层（审计蜂）只负责"系统内的真需系统外的证"的哥德尔补漏

## §3 前瞻 → 场的 Lyapunov 读数（不是预测，是读梯度）

**前瞻 = 在当前投影上读出朝向 P_∞ 的方向导数**：
```
前瞻信号 = −∇rank(P_t)   （rank 的负梯度指得最陡清偿方向）
```
- rank/影子价格/Whittle 指数/义务年龄——**全是同一个 Lyapunov 函数的不同读数**：它们不"预测"未来，它们度量当前投影与 goal 投影的距离场
- fair_leads_to_terminal 的证明结构揭示了前瞻的合法性来源：rank 在非终态严格递降 ⟹ 沿梯度走必达——**前瞻的有效性是证明出来的，不是统计出来的**（这是与 ML 预测的本质区别）
- 多臂情形：Whittle 影子价格=各臂的"单位预算 rank 递降率"——前瞻=比较各方向导数取最陡（这正是 pareto_tick 每轮做的事）
- 反事实前瞻：--simulate 与 replay = 在扰动投影上预读 rank 走向（前瞻的沙盘形态）

## §4 三者统一的投影方程
```
前瞻: 读 −∇rank(P_t) → 选方向（Whittle 定价）
推进: P_{t+1}=P_t⊕discharge → 走一步（义务清偿）
证明: 验证 dist 递降 ∧ 互锁完好 → 留下凭证（链锚+kernel 证书）
——同一不动点算子的读、走、证三相；goal 不在远方，在 rank=0 的投影切面上
```

## §5 对 CI-OS 旧语义的废除声明
- "推进"不再是进度条（%）——进度条是外部观察者的一维投影失真；改用 rank 场（多维可证）
- "证明"不再是评审签字——签字是人读投影的仪式；改用 kernel+锚互锁（可复算凭证）
- "前瞻"不再是规划文档——规划文档是冻结投影；改用 Lyapunov 读数（每 tick 活算）
三者皆为**投影论对行程论的替代**：系统不在时间中旅行，系统在场中重合。
