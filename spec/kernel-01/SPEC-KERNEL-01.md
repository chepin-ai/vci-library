## 0. 基本盘：两个残差

$$\Delta_1 = \mathrm{LLM} \ominus \mathrm{TM} \neq 0 \qquad \Delta_2 = \mathrm{MIP^*} \ominus \mathrm{RE} = 0$$

- **Δ₁≠0（能力残差）**：裸 LLM 不是图灵机（固定上下文+单次前向=有限传导）。这个差**不是缺陷而是引擎**：它精确指示缺什么结构，补一块结构残差就缩一分 —— "LLM 与图灵完备的残差正是动力"。
- **Δ₂=0（验证完备）**：MIP*=RE（Ji-Natarajan-Vidick-Wright-Yuen 2020）——纠缠证明者的交互证明**恰好覆盖全部递归可枚举计算**，验证能力没有天花板。**引擎能产出的任何东西，原则上都可被验证。**

一缺一全：**能力侧永远欠（驱动永恒），验证侧永远够（刹车可靠）**。整个系统是这两条线之间的稳态转换器。

## 2. 最小内核公理集（候选）

$$\mathcal{K}=\{\mathbf{K1..K6}\}$$

- **K1 残差即动力**（Δ-Base 总则）：r≠0⇒FINDING⇒结构生长。系统的全部复杂性来自残差，不来自预设计。
- **K2 结构即算力**：通用性由外挂结构（带/头/寄存器/时钟）提供，模型可以轻（DREAM-02 §4）。
- **K3 验证无顶**：Δ₂=0 ⇒ 任何产出原则上可验 ⇒ 永不接受不可验证的结果（MIP* 递归层）。
- **K4 收敛有条件**：CONV-01 宪章（预算顶/门禁/K_max/η_t/γ<1）——自由以参数为界。
- **K5 决策界遗憾**：不证最优、只界遗憾；影子价格=Whittle 指数；模糊带才升级裁判。
- **K6 边界即 ZKP**：公/私域、人格间、梦与现实之间，只过哈希/承诺/蒸馏物，不过原文与密钥。

**不可规约性论证（反证，每条删一试）**：
- 删 K1 → 无 FINDING 入口，引擎退化为静态脚本（n1a/空白点全部消失）
- 删 K2 → 倒回"大模型即一切"幻觉，蒸馏路线失去合法性
- 删 K3 → 输出无刹车，崩塌/漂移无检测（Nature 2024 结局）
- 删 K4 → 资源爆炸（MC 对照组 ρ=1.2 实测）
- 删 K5 → 最优声称不可证 ⇒ 汇报失真（诚实性失锚）
- 删 K6 → 密钥/内容过界（安全立法崩）
六条删任一，已观测能力死一项 ⇒ **K 在当前证据下不可规约**。
**充分性**：K1 供动力、K2 供算力、K3 供刹车、K4 供稳定、K5 供决策、K6 供边界 —— 六者合取生成现役全部行为（倒推流水账可逐行归因）。

## 3. 与 QF-OS 迁移的关系

内核即种子：QF-OS 的三大特征在 K 中已就位——**折叠**（K6 的公私域 ZKP 边界=亏格通道）、**量子**（K3 的软量子纠缠槽位待真 EPR 升级、IPGSA 在 K4 框架内做全局优化）、**形式化自证**（K1-K6 自身的 LEAN 化 = "规则必形式"的递归封顶，n3/n4/n8 线）。
迁移路径：内核先以 spec 层寄生在 CI-OS 上运行（现状），待 QF-OS 元结构（规则一棵树）成形后整体移栽，链上哈希保证移栽无损（迁移必考）。

## 5. 诚实边界
- K 的不可规约性论证是"当前证据下"的反证，非形式化完备性证明；LEAN 化后由 n8 线复核
- Δ₂=0 是文献级事实（2020）；本系统的 MIP 式实现是其**类比启发**，严格对应待 n9
- 倒推流水账每行有实证，但"残差→模块"的映射唯一性未证（可能有更小的结构集）——K 的极小性（非仅不可规约性）是开放问题 Q8
