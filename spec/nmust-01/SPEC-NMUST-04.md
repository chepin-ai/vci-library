# SPEC-NMUST-04 · 八关系：N/M/Δ 内在结构的范畴学统一（v4.0）

2026-08-24 · usrm 编 · root 问：耦合-嵌入-等价-对称-对偶-蕴含-依赖-桥接，如何关联/统一

## §0 总图

教义三元组（N-Must 轨迹 / M-Code 约束 / Δ-Base 生成）与义务机部件（δ 迁移 / Inv 不变式 / Gen 发生器）之间，八个关系不是修辞清单，而是**范畴论构造的八个标准型**。统一断言：
> **𝔻（教义范畴）→ 𝕸（机器范畴）之间存在一个保持全部八种构造的函子 𝚽；八关系是该函子的八个面。**

## §1 八关系逐个形式化

### R1 耦合（coupling）= 伴随（adjunction）
Δ 与 N 耦合：Gen ⊣ Cl（发生 ⊣ 闭包）——**Gen 是 Cl 的左伴随**：义务由残差自由生成（Gen 是"自由构造"），闭包是遗忘/完成方向。伴随的单位即"残差必生义务"（N12），余单位即"闭义务不留残"。耦合的强度由伴随的唯一性刻画：不是松散的"有关联"，是**普遍映射性质**。
### R2 嵌入（embedding）= 忠实函子
N/M/Δ 分别忠实嵌入 δ/Inv/Gen：**教义语义无损**——两条教义不同 ⟹ 对应机器部件行为不同（忠实性=可区分性保持）。嵌入定理：𝚽 完全忠实 ⟺ 教义文本的每次修订都引起机器行为的可观察差。（反例警戒：死代码=嵌入不忠实，AUDIT-01 A 表的规格死引用即是嵌入破缺的实测）
### R3 等价（equivalence）= 互模拟（bisimulation）
教义即文本 vs 机器即执行之间的**观察等价**：任何教义推演出的义务序列与机器实际清算序列互模拟。检验件：链重放（replay）——把台账重放一遍应与教义推演逐条吻合（审计蜂的重放审计=互模拟检查器）。
### R4 对称（symmetry）= 自同构群
残差↔闭合的**时间反演对称**：每条 raised 义务存在一条到达 legislated 的对偶路径（N9′）；机器/人域双队列互为**任务-资源交换对称**。形式：义务格的自同构群 Aut(L) 非平凡 ⟹ 系统有守恒量（义务总数在迁移下的不变量=开放数+闭合数守恒）。**对称破缺即 FINDING**（某个对称性不再成立=Δ 残差，例：FIFO 对称被人域头阻塞打破→双队列修复）。
### R5 对偶（duality）= Galois 连接
义务与证据互为对偶偏序集：
```
α: 义务 o ↦ 所需证据集 α(o)   （义务是"对证据的索取"）
γ: 证据 e ↦ 被清偿的义务集 γ(e)（证据是"已清偿的义务"）
Galois: o ≤ γ(E) ⟺ α(o) ≤ E
```
对偶定理：义务格 ≅ 证据格的**反序对偶**（证明：由 α/γ 的单调性与复合恒等直接验证 Galois 连接公理）。推论的推论：**每份证据的价值=它清偿的义务数**——证据按对偶定价，这正是 capsules 计分（+0.2~0.3）的理论根据。∎
### R6 蕴含（implication）= FCA 蕴涵格
教义规则=属性蕴涵（前提属性⟹结论属性），全体在 Duquenne–Guigues 典范基下生成（NMUST-02 §2）。蕴含深度=基中长链的长度；蕴含的不可约分解=义务的最小前提集。
### R7 依赖（dependency）= 偏序 + 传递闭包
义务间的 deps（roadmap 已现役）：依赖=偏序 ≺，闭包必须尊重它（o₁≺o₂ ⟹ C(o₂) 不先于 C(o₁) 启动）。**依赖环=系统死锁**：检测=拓扑排序失败即报警（机判）。层级提升定理：deps DAG 的层级数 = 级联 L0-L3 的形式根据（依赖深度超限才上浮）。
### R8 桥接（bridging）= 保结构函子（跨域）
会话端⇄CI端、机器域⇄人域、理论⇄代码——桥=两个范畴间保结构的映射。现役桥：双链互引（叙事链⇄决策链）、capsule 总线（会话⇄业务仓）、lobby（人⇄机）。**桥的不变式**：桥两端的状态互译无损（链 seq 互引=桥的同构性检查点）。断桥=信息孤岛的生成瞬间（例：60 天 cron 停用=时间桥断裂，keepalive 是桥维护件）。

## §2 统一定理

**定理（八关系同构）**：在 𝚽:𝔻→𝕸 完全忠实的条件下，八关系在两侧一一对应且可互译：
- 耦合↔伴随、嵌入↔忠实、等价↔互模拟、对称↔自同构群、对偶↔Galois 连接、蕴含↔蕴涵格、依赖↔偏序闭包、桥接↔保结构函子
**证明骨架**：R1/R5/R6 为格论构造（标准定理引用）；R2/R3/R8 为函子性质（定义展开）；R4/R7 为序结构（群作用与 DAG 层级）。统一的实质：**教义即范畴，机器即其在可执行范畴中的像；八关系=像与原像之间必保的八种结构**。
**推论（米田共识 M4 的执行形态）**：一条教义由它生成的全部义务唯一刻画（Yoneda：对象由它的 Hom 集决定）——教义不再靠文本权威性，靠它产生的义务闭包。∎
