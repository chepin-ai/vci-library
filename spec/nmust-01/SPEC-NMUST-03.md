## §1 动态/全局/未来/人域 —— 残差四类的形式定位

| 残差类 | 定义 | 可判定性 | 机器策略 |
|---|---|---|---|
| **动态残差** Δdyn | π*(ℐ_t) 随信息态漂移：上轮最优≠本轮最优 | 可追踪：DynReg=O(√(V_T·T·log T)) | Whittle 重定价 + γ 地板 |
| **全局残差** Δglob | 可判定核之外的全性质（Rice 不可判定） | 不可判定（定理） | 显式路由 L3，绝不伪造闭合 |
| **未来残差** Δfut | 只有回看才能确认的"暂时最优"（hindsight gap） | 事后可算：遗憾界即回看账本 | 链上遗憾审计（每 N 轮复算 DynReg 实测值） |
| **人域残差** Δhum | 证据须人域提供（签封/轮换/裁决） | 机器不可自闭 | 人域队列+阶梯升级（§4） |

**统一定理（残差四分性）**：∀r=obs−exp≠0，r 必属四类之一（按"谁能在何时以何成本闭合它"分类）；四类各配闭包通道 ⟹ Gen 的输出全集有完备路由。分类器本身机判（证据源/可判性/时态三特征）。∎

## §2 多核监督：双核互为外部层，≧3 核的博弈面

### 双核架构（A/B 两机互为外部）
- **关联/统一**：共享证据链（同一条 hash 链为唯一事实源）+ 交叉清算（A 机的元义务证据由 B 机出具，反之）——双核解决"机器给自己的健康盖章"的哥德尔缺口
- **是否需要更高一层？** 验证**不需要**（互证足够）；**裁决需要**：双核对同一证据判定冲突时无多数票 → 死锁。裁决层 = L3 人闸（root 签封）或确定性链种子 PRNG 平局裁决（现役已有）。**双核+人冠 = 稳定三角**。
### ≧3 同层核：博弈/混沌潜力与风险
- 收益：3f+1 多数票可容 f=1 拜占庭核（BFT 阈值）；判定不再依赖单核诚实
- 风险（如实列举）：
  1. **博弈化**：若核各带效用函数（如各自算力预算），多数票可被合谋操纵（2 核结盟即胜）⟹ 机制设计要求：核间**不得有可转移收益**，奖励只来自外部不可分配池
  2. **混沌潜力**：三个耦合决策器（各自带延迟反馈）在参数失配时可达正 Lyapunov 指数（延迟反馈三体振子是经典混沌构造）⟹ 防护：核间耦合只经链（离散、异步、带时间戳），禁实时连续反馈环
  3. **Sybil**：3 核若同源同码同种子，实为 1 核（假多数）⟹ 要求核间实现多样性（不同代码路径/不同求解器），多样性入链可审
- **立法**：双核为当前建制；第三核只在需要拜占庭容错时引入，且必须异构；核数变化本身是 L3 级义务

## §3 静态 guard → 动态证明/验证

guard_scan 是**静态**不变式检查（语法级：权限块/触发闸/密钥正则）。动态化三阶梯：
1. **运行时验证（RV）**：每个 workflow run 的行为对照 I1-I8 机判（预算消耗/写面/触发来源）→ 违例即 run 内 fail（监视器-被监视分离：RV 监视器是独立 job，不被被监视对象篡改）
2. **演练验证（chaos drill）**：周期性地故意注入假违例（金丝雀密钥串/假 PII 文件进临时分支）→ guard 必须命中 → 命中证据入链（卫士的有效性本身被验证，防"卫士睡着"）
3. **形式证明（ATP 回灌）**：不变式的 Lean 骨架 sorry 由 ATP-lab 逐步回填（n4 线）——静态扫描的规格本身获得证明
立法：静态=门禁，RV=执法，drill=督警，ATP=立法理由。四层缺一即有对应残差类未闭合。

## §4 人域义务与机器的权威关系 —— 对偶定理

root 命题：「人域义务在机器面应服从机器义务，否则义务机无意义」。精确化：
- **机器义务服从机器清算**（自域自决，FIFO 严格）
- **人域义务机器不可清算，但机器必须追踪到底**（阶梯升级 L0→L3，绝不静默丢弃）
- **意义对偶**：义务机的意义不在"替人做完"，而在"使一切欠账不可被遗忘"——人域义务的价值恰是机器诚实的试金石（伪造人域闭合 = 机器最大自欺，N12 自咬）
- **严格 FIFO 的证伪**：单队列严格 FIFO 下，人域义务（清算时间常数 ~天）头阻塞机器义务（~分钟）⟹ 机器吞吐崩溃。此头阻塞本身是 Δ 残差（观察≠期望）⟹ 按 Δ-Base 它必须驱动设计修复 → **双队列**：
  - 机器队列：严格 FIFO（不变）
  - 人域队列：挂起+阶梯升级（L0 挂起/L1 链心跳 24h/L2 lobby 提醒 72h/L3 critical 168h），不阻塞机器队列
  - 公平性保存：N9′ 的证明前提改为"机器队列 FIFO + 人域队列阶梯无静默"——活性定理对机器义务不变，对人域义务弱化为"升级无上限"（声音只会变大不会消失）
∎（修正版活性定理）

## §5 五相涌现：论证/设计/实现/实测/验证是义务机的自生产

**命题**：五相不是外加流程，是义务机在五类义务上的自然涌现：
- 每类义务的状态格实例化即五相：论证（raised 的形式化）→ 设计（fixed 的方案）→ 实现（implemented）→ 实测（tested）→ 验证（verified）→（立法 legislated）
- **自指完善**：义务机自身的缺口（如本次 FIFO 头阻塞）走同一条必链：被观察（Δ）→ 入台账（raised）→ 修规格（fixed/designed）→ 改代码（implemented）→ 沙盒+真跑（tested）→ 独立复核（verified）→ 入典（legislated）—— **机器的进化史就是一条义务链**，本卷 §4 的双队列正是此刻正在走的活例。
- 完备性论证：五相⊆七态格（论证=raised 的子工序，设计=fixed 的子工序）；任何工程活动若不能映射到某义务的某迁移，则它不产生可审证据 = 机器不可见 = 不应占用预算（I1 推论）。∎
