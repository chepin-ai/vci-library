## §1 义务闭包机如何解构 N-Must / M-Code / Δ-Base

三类教义在机器中各占一个正交部件，无一遗漏：

| 教义 | 机器部件 | 数学角色 |
|---|---|---|
| **Δ-Base**（残差即 FINDING 等 3 条） | **义务发生器** Gen: obs ↦ O_new | 观察与期望之差 → raised 义务；是机器的"感官" |
| **N-Must**（首报必跟进…迭代必见效 8 条） | **迁移图** δ: 必链七态格上的合法边 + 每边的证据谓词 | 义务的"法定人生轨迹"；leads-to 边集合 |
| **M-Code**（守护者常驻/米田共识等 7 条） | **状态约束** Inv: 任何迁移前后必须成立的谓词（I1-I8 为其执行例） | 机器的"体质"，不可迁移破坏 |

统一形式：义务机 **𝕸 = ⟨O, Gen, δ, V, Inv, E⟩**（义务集/发生器/迁移图/证据谓词族/不变式族/证据库）。
- Δ 管"何时生"，N 管"往哪走"，M 管"走的时候不许坏什么"
- 解构的完备性论证：任何一条教义语句必为三类之一（生成/轨迹/约束），否则它不含可执行内容（不产生义务、不要求迁移、不限制状态 = 纯修辞，不入机器）。∎

## §2 最小不可约完备集闭包：构造与作用

### 定义
规则集 R 的闭包 Cl_R(O₀) = 包含 O₀ 且在 R 下封闭的最小义务集。
- **完备**：Cl_R(全部历史事件) ⊇ 全部实际应生义务
- **不可约**：∀r∈R, Cl_{R\{r}} ⊊ Cl_R（删任何一条就有义务类变孤儿）

### 自构造算法（三步，借 FCA 的 Duquenne–Guigues 典范基）
1. **采集**：遍历链/台账/F 表，得义务实例集 O_hist（今日已有：seq116 事件、F1-F7 预警、各节点 findings）
2. **归纳**：对 O_hist 做反统一（anti-unification）泛化出候选规则——例：「F1 预警→未整改→泄漏」与「cron 60 天→未 keepalive→停转」反统一得元规则 **「时限/边界类预警未整改必失效率=1」**（K7 正是这样被归纳出来的）
3. **约简**：在蕴涵格上求典范基——属性=证据谓词，蕴涵=规则；Duquenne–Guigues 基定理保证**唯一最小基存在且可有限步算出**（属性集有限时）

### 它如何发挥重大作用（四用）
1. **审计罗盘**：新义务进来先查可否由基推出——推不出 ⟹ 基不完备 ⟹ 基自己要生义务（N12 自指生效）
2. **承重墙标识**：基元素被删即出现孤儿义务类 → 基的每个成员都是"断了就塌"的 doctrinal load-bearing wall
3. **漂移探测器**：基对历史完备但对未来不完备是常态；新义务类出现 = 基版本号 +1 的时刻（基演化史本身入链）
4. **教学/交接集**：新成员（人或蜂）只需学基——其余皆可推。基是教义的最小充分统计量

## §3 N9–N12 详证 + 活性定理

### N9 必链完全性：□(raised(o) ⟶ ♦legislated(o))
**无条件版是假的**——若无公平调度，某义务可永远挨饿（n7 饥饿就是活体反例：running 而不在 frontier ⟹ 永不调度）。诚实形式：
**定理 N9′（公平性下完全性）**：若 sweeper 每轮处理最老未闭义务且证据谓词可判，则每条义务在有限轮内到达 legislated 或 wontfix。
**证明**：设第 t 轮最老未闭义务为 o_t。义务按年龄全序；每轮 o_t 要么推进一格（证据成立），要么被显式标记 wontfix（L3 签封），要么暴露证据不可判——但 N10 的谓词设计全为可判（commit 存在/run 成功/匿名抓取/入典 commit 均为可判定查询），矛盾。故每轮最老者严格推进或终结。态格高 7，义务数有限 n ⟹ 至多 7n 轮全闭。∎
**推论**：N9 的证明暴露了它自己的隐藏前提（公平性）——这正是形式化的价值：它把"应该可以吧"变成"需要 FIFO 这条硬规定"。

### N10 迁移必有据：证据谓词族 V
| 迁移 | V（机判定义） |
|---|---|
| →fixed | ∃ commit c: c 引用 o.id 且 diff 触及病灶文件 |
| →implemented | 新代码/配置落地且可被调用（dry-run 或接口可达） |
| →tested | ∃ run r: r.conclusion=success 且 r 触及该实现 |
| →verified | 独立路径复核（匿名 raw / 哈希复算 / 对拍）结果一致 |
| →legislated | ∃ commit c': KERNEL/kit/INDEX 等正典文件增益且引用 o.id |
**单调性引理**：证据一旦入链即为真永真（append-only + hash 锚）⟹ 迁移无回退污染。∎

### N11 证据链锚
证据 e 入链 ⟹ 篡改需找 sha256 截断 96bit 碰撞 ⟹ 敌手成功概率 ≤ q²/2⁹⁷（生日界，q=查询数）。证据的单调性在密码界内对多项式有界敌手成立。∎（密码学假设显式声明：本定理的安全性归约到 sha256 抗碰撞）

### N12 残差即新义务
O_{t+1} = Cl(O_t ∪ Gen(obs_t))。Gen 单调 ⟹ 算子 T(O)=Cl(O∪Gen(obs)) 在有限义务格上单调 ⟹ **Tarski：最小不动点存在**；Kleene 迭代 ≤ 格高轮收敛。该不动点即"全网义务闭包"——**存在且可算**（对比 §5 的最优解）。∎

### 活性定理（总）
在 FIFO 公平 + 谓词可判 + wontfix 需 L3 签封下：∀o∈O，至多 7|O| 轮内 o 到达终态（legislated/wontfix）。证明=N9′ 证明的全量化。∎

## §4 帕累托局部迁移 → 动态全局最优

### 问题的精确化
root 指出：全局最优一直变动，且只有未来回看才能确定"暂时"最优。这正是**动态遗憾（dynamic regret）**框架的标准设定：
- "暂时最优" = 给定信息态 ℐ_t 的 Bayes/Whittle 最优 π*(ℐ_t)
- "未来回看的最优" = hindsight 基准（最优动作序列）
- 目标不是到达某个固定 π*，而是**追踪漂移的 π*(t) 且追踪误差次线性**

### 定理骨架（追踪界）
设环境为分段平稳（变化预算 V_T = 漂移总量），自适应 Whittle + γ 地板探索 ⇒ 动态遗憾
**DynReg(T) = O(√(V_T·T·log T))**（Besbes–Gur–Zeevi 2015 非平稳 bandit 界；对抗情形对应 Exp3.S, Auer 2002b）
每步"最小证据满足验证谓词"= 不过证不欠证 = 在证据维度上同样跑 Whittle（证据获取有成本 c_e，按影子价格取最值证据）。
**故**：局部帕累托迁移 + 有界探索 + 参数递归重拟合 ⟹ 对漂移全局最优的追踪误差次线性 —— "全局最优在动"不是障碍，恰是该界覆盖的情形。
**诚实边界**：不宣称到达"那个"最优；宣称的是可量化的追踪误差上界。回看确定性由遗憾界保证（相对 hindsight 基准欠多少是算得出的）。

## §5 必链遍历能否解算"全网最优解"？—— 存在性二分

- **义务闭包：存在且可算**（§3 N12 的 Tarski 不动点）——全网"该做什么"的闭包可穷尽
- **全网最优解（所有安全/正确性质全真）：不可判定**——Rice 型论证：workflow/代码语义的一般性质非平凡即不可判定；任何形式化声称"算出了全网最优"都是假的
- **可判定核 + 人域边界的二分是定理而非妥协**：I1-I8 为语法级可判定不变式（机器保证），其余性质路由 L3（K6 边界即 ZKP 的对偶：边界之内可证，边界之外可验人）
**立法**：机器诚实地保证可判定核；不可判定部分显式标记 human-gate，绝不伪造闭合（o-root-rotate 挂起态即此诚实的活体展示）。

## §6 义务臂优先 = 字典序最优（与 Whittle 的统一证明）

**模型**：义务=硬约束（违例成本 C 未知且可能灾难级），研究臂=目标最大化。
**定理（可行性优先）**：对未知无界的 C，任何延迟修复约束的策略期望成本 ≥ p·C，其中 p>0 为违例暴露概率；C 无界 ⟹ 无有限研究收益可补偿 ⟹ **先可行后最优是唯一有理序**。
**与最优判据的统一**：字典序 = 罚因子 λ→∞ 的加权和极限；Whittle 影子价格在可行残差预算 B−Σc(义务) 上计算。即：
```
sweeper 决策 = argmax_π  Whittle(研究臂 | 预算 − 义务清算成本)  s.t. 义务臂先清算
```
一层字典序，内部 Whittle —— 两个判据是同一优化在不同约束层的投影。∎

## §7 oblig_tick 的意义、监督与自我约束

### 意义/效果
教义从文本变成调度器强制的优先级；每条规则获得可执行的证据检查器；义务年龄成为一等公民（最老优先清算）——"欠账必还"从美德变为数据结构。

### 谁来评估/监督——四层，无单点
1. **谓词层**：机器不能无证自证（N10）——证据必须是链锚工件
2. **元义务层（N8/自指）**：义务机自身的健康是一条义务（漂移哨兵项：oblig_tick 久未清算 ⟹ 自报警）——**机器不得豁免自己**，否则 N12 自咬
3. **人闸层（L3）**：wontfix 与 level-3 级联须 root 签封
4. **外部层**：独立审计蜂周期性重放链与台账（AUDIT-01 模式制度化）

### 自我约束
- 预算不变式 I1/I2 给机器上笼头
- K7 使机器自己的预警也进自己的台账（自吞义务）
- 自我指涉的悖论防护：元义务的清算证据必须来自**外部层**（审计蜂），防止机器给自己的健康自我盖章——监督的哥德尔式安排：系统内的真，需系统外的证。
