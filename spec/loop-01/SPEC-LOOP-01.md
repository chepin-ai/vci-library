## 1. 主循环（五相）

$$\mathcal{L}:\quad \mathcal{K}\;(\text{内核})\;\xrightarrow{\;\text{构造}\;}\;\mathcal{T}\;(\text{工具链})\;\xrightarrow{\;\text{判定}\;}\;\mathcal{J}\;\xrightarrow{\;\text{残差}\;}\;r\;\xrightarrow{\;\text{级联}\;}\;\Delta\mathcal{K}/\Delta\mathcal{T}\;\longrightarrow\;\mathcal{L}\dots$$

| 相 | 内容 | 现役机制 |
|---|---|---|
| **构造** | 内核残差倒推新模块（倒推流水账法） | DAG 节点→蜂/CI 作业→模块 |
| **判定** | 双轨：代码判定（冒烟/对拍/MC）+ 形式判定（LEAN/ATP） | atp-lab/tn-lab/kaggle-compute/Rules.lean |
| **残差** | 判定输出与内核预期之差 | r≠0⇒FINDING（Δ-Base/K1） |
| **级联** | 残差的分层处置规则（§3） | 本规格新增 |
| **递归** | 处置结果改写构造/判定自身 | 参数级自修改（STRAT-02 红线内） |

## 2. 两环节的判定（"判定此两环节"）

**环节一：构造的判定** —— 模块称"已建成" ⟺ 过三关：冒烟（CI 实跑绿）+ 接口契约符合（楔的 trans/tn 签名）+ 链上哈希登记。缺任一 = 构造残差。
**环节二：判定的判定** —— 判定器自身的可靠性：代码判定的对拍率（两边夹一致性，M6 检验必反复）；形式判定的 soundness 由证明器内核承担（LEAN kernel 可判定性——**证明检查是可判定的，故判定环节的停机无争议**）；判定器分歧 = σ 超阈 ⇒ 锦标赛（REVP-01）。
两环节互判：构造残差大 ⇒ 判定加严（阈值收紧）；判定残差大 ⇒ 回炉构造判定器（级联上行）。

## 3. 残差级联规则（cascade）

```
level 0 模块残差     → 本层重构（预算内重试/换道 R1-R3）
level 1 接口残差     → 楔修订（契约改版，兼容检查）
level 2 策略残差     → 参数回调（β,γ,ε,θ，Robbins-Monro 步长）
level 3 内核残差     → human-gate（结构级自修改红线，STRAT-02 §3）
```
- **级联方向**：先本层、后上行；本层连续 k 次未消 → 强制上行（上浮传播）
- **级联刹车**：每上浮一级，预算消耗放大 ⇒ 上浮本身是稀缺的（级联深度 ≤3，顶格即 root）
- 残差记录全入链：级联历史=系统的免疫档案

## 4. 不动点/停机：帕累托贪婪均衡（终态定义）

$$\pi^* = \mathcal{L}(\pi^*)\quad\text{且}\quad \forall a\in A_{active}:\ \Delta u(a)<\varepsilon,\quad r_{total}<\theta_r,\quad \lambda'\bar\beta/B<1$$

**均衡的四重刻画**（四条已证线的合流）：
1. **无改进**：所有现役臂边际增益 <ε（T1 停机条件全体满足）
2. **无残差**：判定全绿、级联静默（r_total 低于阈）
3. **无拥堵**：臂流被门禁吸收（T2 稳定条件）
4. **无偏决策**：Whittle 指数排序已达当前信息下的渐近最优（T3）
⇒ 系统停留在**帕累托贪婪均衡**：不是"没有事做"，而是"按当前知识，任何预算再分配都不改善"——探索预算 γB 仍保底运转（均衡含恒定的探索流，防锁死）。

**存在性**：合成算子 𝔏=构造∘判定∘级联 在参数流形上收缩（折扣+步长衰减，STRAT-02 §3）⇒ Banach 不动点存在唯一。**可达性**：Lyapunov 势 Φ=Σ残差+Σ(1−score) 每主循环严格下降或触发上浮；上浮顶格（level 3）即停机于 human-gate —— **停机于 root 是设计终态，不是故障**。
